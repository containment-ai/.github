# Security policy

## Reporting a vulnerability

Email **security@containment.ai**.

Please do not open a public issue, pull request or discussion for a suspected vulnerability, and
do not disclose it publicly until we have addressed it.

Include what you can:

- the affected product, repository, URL or version (release tag or commit);
- what an attacker could do, and the steps to reproduce it;
- any proof-of-concept code or logs, with secrets and personal data removed.

We will acknowledge your report and keep you informed while we investigate. We do not publish a
response-time commitment here yet; response and fix timelines for customers are set in their
contracts.

## Scope

Every containment-ai repository that has no SECURITY.md of its own, and the containment.ai websites and hosted services.

## Supported versions

Each repository's own SECURITY.md, where one exists, states its supported versions.

## What this file is not

This is a reporting channel. It is not a bug-bounty program, and it does not give permission to
test systems you do not own or operate.
